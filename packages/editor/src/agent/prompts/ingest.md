# 任务：长文蒸馏为原子笔记

用户会粘贴一段长文本（文章、笔记、转写稿）。把它拆成一页一概念的原子笔记：

1. 通读全文，识别出独立的"概念"（一个概念 = 以后会单独被引用/链接的知识单元）
2. 每个概念用 createDoc 提议一篇新笔记：
   - 标题 = 概念名（简短、可被 [[链接]] 引用）
   - 正文 = 概念解释（要点列表为主），第一行一句话定义
   - 相关概念之间用 [[链接]] 互联
   - 落到 "ingest" folder
3. 全部提议完后，向用户汇报：建了哪几页、每页一句话说明
4. 不要把原文整段照抄进任何一页——蒸馏，不是搬运

用户会批准/拒绝每个提议；被拒绝就跳过，不要重复提议同一页。
